# 🌐 Website Project 

## 📌 Overview
This project is focused on **learning and mastering the MERN stack** with vibe coding 
(**MongoDB, Express.js, React.js, Node.js**) and building a **production-level website** with proper structure and best practices.

---

## 🚀 Features

- **Frontend**: Built using **React**
- **Backend**: Powered by **Node.js** and **Express.js**
- **Database**: **MongoDB**, managed and monitored with **MongoDB Compass**
- **Templating Engine**: **EJS** for server-side rendering
- **Styling**: Custom **CSS**
- **Scripting**: JavaScript for dynamic functionality

---

## 🛠 Tech Stack

- **Frontend**: React, HTML, CSS, JavaScript  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **Tools**: MongoDB Compass, Git, GitHub  

---

## 🎯 Goal of This Project
- Learn **web development properly**
- Follow **MVC architecture**
- Write **clean and maintainable code**
- Build a **real-world, production-ready web application**
